UNICA Manager Android 1.0.2 - GitHub Actions

Il workflow reale deve trovarsi ESATTAMENTE qui nel repository:
.github/workflows/build-android-aab.yml

Se caricando i file dal browser GitHub la cartella nascosta .github non compare:
1. Apri il repository su GitHub.
2. Vai su Actions.
3. Clicca "set up a workflow yourself" / "New workflow".
4. Incolla il contenuto del file visibile build-android-aab-1.0.2.yml.
5. Salva con nome .github/workflows/build-android-aab.yml e fai Commit.

Questa versione supporta sia avvio manuale (Run workflow) sia avvio automatico quando vengono modificati i file Android o il workflow.
